29/09/2016 - v1.1.2
  • Added "Scoped" and "Unscoped" links above the weapon list
    • Scoped link checks Splatterscopes + Scoped E-liters and unchecks Splat Chargers + Regular E-liters
    • Unscoped link does the opposite
    • Bamboozlers and Squiffers aren't affected by either
  • Added a checkbox that tries to evenly distribute weapons across teams based on range

  • Changed default chance for free picks from 1% to 0% (disabled by default now)

29/02/2016 - v1.1
  • Fixed: when loading saved settings, it would select all ranked stage/mode combinations that came after the last selected combo in the table
  • Added: a warning when you haven't selected enough stages/weapons
    • (this used to silently fail - nothing would happen and it was confusing.. now it will tell you what's wrong)
  • Added: option to (de)select ALL stages at once
  • Added: it now shows you how many unique stages, unique modes and total combinations you have selected
  • Added: option to rotate stages and/or modes wherever possible
    • It'll try not to repeat stages until all stages have been selected (same for modes)
    • If it runs into a situation where that's not possible, it'll try to ignore these options until it's possible again
  • Added: clicking a randomized stage/mode combo will uncheck it in the stage table (saves you some time not having to scroll up)
  • Added: option to create a shareable code to send to others that they can then use to load your selected stages
  • Added: option to give both teams the same weapons
  • Added: free picks
    • Can set the chance that someone gets to choose their weapon instead of being assigned one (set the percentage to 0 to disable)
    • Includes the option to give both teams an equal amount of free picks
  • Added: ability to select exactly what weapons the randomizer is allowed to pick
    • Doesn't include certain weapons (octoshot/octo valley/amiibo challenge) if the corresponding checkboxes aren't checked
    • (Will select all weapons by default so nothing should change for you if you don't want to use this feature)
23/12/2015 - v1.0.1
  • Added: options to randomize team members
    • Can keep the same randomized teams for all sets or randomize the teams for every set.
    • If you enter more player names than the amount of players you're randomizing weapons for, it'll pick random players.
